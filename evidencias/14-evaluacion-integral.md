# Actividad 14 — Matriz del Escenario Integral

| N.º | Problema | Principio afectado | Riesgo | Control propuesto |
| :---: | :--- | :--- | :--- | :--- |
| **1** | Acceso directo de todo el personal de analítica a la tabla de producción. | **Confidencialidad** / Mínimo Privilegio | Fuga de información por empleados malintencionados o accidentales (*insider threat*). | Implementar Control de Acceso Basado en Roles (RBAC). Mover analítica a un Data Warehouse o réplica separada. |
| **2** | El área de analítica accede a datos identificables (`nombre`, `correo`, `telefono`) cuando solo necesita estadísticas. | **Minimización** | Exposición innecesaria de PII (Información de Identificación Personal) que incrementa el impacto de una filtración. | Proporcionar vistas anonimizadas o datos agregados a analítica, ocultando campos identificadores individuales. |
| **3** | Retención de datos de hace 12 años sin justificación clara. | **Limitación del Plazo de Conservación** | Almacenamiento de datos "zombis" u obsoletos que aumentan innecesariamente la superficie de ataque y el impacto de un robo. | Definir y ejecutar una política estricta de borrado de datos históricos que ya no tengan finalidad legal u operativa (ej. conservar solo 5 años). |
| **4** | Ausencia total de una política documentada de retención. | **Responsabilidad Proactiva** (*Accountability*) | Incapacidad de demostrar cumplimiento ante auditorías, y retención indefinida por defecto por falta de directrices. | Redactar, aprobar y formalizar una política de retención y disposición final de datos, alineada con obligaciones legales y fiscales. |
| **5** | Entrega de copias completas de la base de datos de producción a los desarrolladores. | **Integridad y Confidencialidad** / Seguridad | Fuga masiva de datos reales al sacarlos del entorno productivo seguro hacia entornos de desarrollo, típicamente menos protegidos. | Prohibir el uso de PII real en desarrollo. Usar datos sintéticos o anonimizados para pruebas. |
| **6** | Uso de información real de clientes en copias de desarrollo para realizar pruebas. | **Seguridad** | Los desarrolladores no autorizados tienen acceso a datos sensibles. Mayor riesgo de ataque externo si los entornos de desarrollo están expuestos. | Implementar herramientas de enmascaramiento dinámico o estático de datos (*Data Masking*) para todas las copias de bases de datos destinadas a pruebas. |
| **7** | Marketing utiliza los correos para campañas promocionales sin evidencia de consentimiento documentado. | **Licitud y Consentimiento** / Finalidad | Envío de spam legalmente riesgoso; multas por violar la voluntad del usuario y daño reputacional a la marca. | Auditar registros de consentimiento. Implementar un sistema Central de Preferencias (Lista de Exclusión / *Suppression List*) y respetar *opt-outs*. |
| **8** | Falta de documentación clara sobre qué finalidad corresponde a cada dato. | **Transparencia y Finalidad** | Incapacidad de justificar legalmente la recolección y uso de cada campo (ej. RFC), lo que hace al tratamiento ilegal bajo normativas de privacidad. | Realizar un mapeo de datos y actualizar el Aviso de Privacidad detallando la finalidad específica de cada campo recolectado. |
| **9** | Combinación de datos altamente sensibles (`rfc`, `telefono`, `nombre`) en una sola tabla desprotegida. | **Confidencialidad** / Seguridad | Un atacante que acceda a esta única tabla puede realizar robo de identidad completo, fraude fiscal o suplantación de identidad. | Implementar cifrado a nivel de base de datos (TDE) para campos críticos (`rfc`) y considerar la segregación física de datos muy sensibles. |
| **10** | Inexistencia de gobernanza general de datos y controles técnicos en la base de datos (PostgreSQL). | **Responsabilidad Proactiva** / Privacidad por Diseño | Falta total de trazabilidad, incapacidad para responder a solicitudes de derechos ARCO y desprotección general de los activos de información. | Crear un comité de gobierno de datos, nombrar un Oficial de Privacidad y configurar controles técnicos avanzados (Audit logs con `pg_audit`, cifrado, enmascaramiento). |
